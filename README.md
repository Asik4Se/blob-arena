# ブロブアリーナ（仮）

Agar.io風の複数人対戦ゲーム。人数無制限、サイズ違いのNPCと「ヌシ」で少人数でも盤面が賑わう。

## 遊び方

- マウスの方向へ移動（スマホは画面左のスティック）
- Space：分裂（スマホは「分裂」ボタン）
- W 長押し：射出（スマホは「射出」ボタン）
- Q / E：スキル（スマホは右側のスキルボタン）。タイトル画面かロビーで、8つの中から2つ選ぶ
- 1試合5分。終了した瞬間のスコア（＝現在の質量）が一番高い人の勝ち。食べられるとスコアは0に戻る

## 起動（ローカル）

Node.js 18以上があれば、追加のインストールは不要です。

```
node server.js
```

ブラウザで http://localhost:3000 を開き、「部屋を作る」→ 表示された4桁コードを友だちに伝える → 友だちは「入る」。
同じWi-Fi内なら、友だちは `http://<このPCのIPアドレス>:3000` で参加できます。

## 公開（Render）

ルーンサークルと同じ手順で公開できます。

1. Renderで「New」→「Web Service」→ このリポジトリを選ぶ
2. 設定：Language `Node`、Branch `main`、Build Command `npm install`、Start Command `node server.js`、Health Check Path `/healthz`、Instance Type `Free`
3. 「Deploy Web Service」を押し、発行されたURLを共有すれば、誰でも部屋を作って遊べます

`render.yaml` を同梱しているので、「New」→「Blueprint」でこのリポジトリを選ぶと自動で設定されます。

無料プランはしばらくアクセスがないとスリープし、最初の接続に30秒ほどかかります。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `public/core.js` | ゲームのルール本体（サーバーとブラウザで共通）。数値は先頭の `CFG` で調整 |
| `public/client.js` | 描画・HUD・操作・ひとり練習モード |
| `public/index.html`, `public/style.css` | 画面 |
| `server.js` | 部屋コード管理と試合の計算（毎秒20回） |
| `ws.js` | 外部ライブラリなしのWebSocket通信 |
| `tools/build-solo.js` | ひとり練習版を1ファイルHTMLにまとめる（`node tools/build-solo.js` → `dist/`） |

## 実装済みの仕様

- NPC：ちびブロブ、群れ（6体隊列）、ハンター、グラトン（分裂攻撃）、ヌシ
- NPC総数 = 40 − 人数×3（最低10体）。食べられたらすぐ新しいNPCが湧く
- ヌシ：最大プレイヤーの1.3倍（最低800）を目指して少しずつ育つ（1秒に約2%）。ヌシより大きいプレイヤーが近くにいる間は育たないので、追いかければ食べられる。食べられるとすぐ、食べた人より大きい新しいヌシが遠くに湧く。動きは遅め
- 湧き位置の安全：NPCは自分より小さいプレイヤーから900px以上離れた場所に湧き、3秒間は半透明（食べる・食べられるなし）。プレイヤーのリスポーンも安全な場所＋3秒無敵
- 大きいほど遅い（質量20と500で約3倍差）
- 逆転イベント：賞金首（1位が2位の1.5倍以上で発生、食べると1.5倍獲得）、流星群（1分ごとに必ず来て20秒続く。5分の試合で4回。質量300以上は破裂）、ゴールデンエサ（毎分、下位の近くに出やすい）、ラストフィーバー（残り1分でエサ2倍）
- スキル（2つ選択）：ダッシュ（2.5秒 移動1.7倍・再使用10秒）、シールド（5秒 食べられない・割れない・30秒）、マグネット（5秒 エサを吸い寄せる・18秒）、ワープ（進行方向へ瞬間移動・15秒）、ステルス（6秒 ほかの人とNPCから見えない・25秒）、トラップ（背後にウイルスを置く、30秒で消える・20秒）、合体（分裂したセルを一瞬でひとつに戻す・30秒）、衝撃波（まわりのセルとウイルスを吹き飛ばす・20秒）。数値は `public/core.js` の `SKILLS`
- 右上：プレイヤーの現在スコアのランキング（上位10人＋自分）
- 10人を超えるとマップが広がる
